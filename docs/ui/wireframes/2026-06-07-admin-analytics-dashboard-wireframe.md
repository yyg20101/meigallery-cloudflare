- 导出按钮在移动端仅 owner 可见，且可折入更多操作，避免挤压时间范围。

## 3. 子页面通用线框

```text
┌ 页面标题 / 说明 / 时间范围 / 刷新 / 导出 ┐
├ Tabs                                       ┤
├ Usage 或健康条                             ┤
├ 页面级 KPI 2-4 个                          ┤
├ 主表格或漏斗矩阵                            ┤
├ 详情抽屉 / 异常队列 / 空状态                ┤
└ 分页、排序、导出状态                        ┘
```

子页面重点：

- 来源：访问 -> 详情 -> 联系 -> 注册 -> 会员发放的来源矩阵。
- 内容：页面、图库、标签和搜索结果页的访问质量。
- 链路：入口、退出、跳出和路径边。
- 点击：raw、effective、duplicate 和重复点击率。
- 时长：平均、P50、P75、深度浏览率和跳出。
- 邀请：邀请码落地、注册、会员发放和状态管理。
- 健康：accepted、rejected、duplicate、sensitive blocked、采样和 D1 usage。

## 4. 验收关注点

- 360px、768px、1024px、1440px 不出现横向滚动。
- 采集关闭时显示“数据采集未开启”，不展示 0 值假象。
- 非 owner 不渲染导出和 session 明细入口。
- 默认报表读取聚合表和摘要表，不扫描 `analytics_events` 全量明细。
- 空数据、查询失败、权限不足、聚合延迟和成本告警都要有独立状态。
