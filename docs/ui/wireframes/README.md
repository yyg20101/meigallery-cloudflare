# UI 线框图留存说明

更新时间：2026-05-26

`.superpowers/brainstorm/` 中的线框图不纳入版本管理，不能作为长期唯一设计依据。后续关键线框图应导出到本目录，或以截图、PDF、HTML 快照形式保存。

## 必留页面

- 首页：桌面端和移动端。
- 图库详情页：桌面端和移动端。
- 发现/搜索页：标签筛选、搜索建议和无结果状态。
- 登录/注册/用户中心：默认状态和错误状态。
- 后台工作台：Dashboard、图库管理、导入任务。

## 命名规范

```text
YYYY-MM-DD-page-name-viewport.ext
```

示例：

```text
2026-05-26-home-desktop.png
2026-05-26-home-mobile.png
2026-05-26-admin-dashboard-desktop.html
```

## 留存要求

- 每个导出物需能对应到 `docs/UI_DESIGN.md` 的具体页面或组件。
- 更新线框图时，在 PR 或提交说明中写明变更原因。
- 线框图不得包含未经授权的真实人物图片、联系方式截图、付款凭证或隐私信息。
- 如只保存截图，必须覆盖 360px、768px、1024px、1440px 中相关的关键视口。
