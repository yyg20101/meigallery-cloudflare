# UI 质量审阅与验收清单

更新时间：2026-05-26

本文用于约束 `docs/UI_DESIGN.md` 的设计质量、当前可验收范围和页面/组件验收标准。若 UI 历史规划与当前实现状态冲突，以 `docs/PROJECT_STATUS.md`、`docs/PRD_QUALITY_REVIEW.md`、`docs/TECHNICAL_SPEC.md` 和本文为准。

## 1. 审阅结论

现有 UI 文档已经确定“珍珠杂志感 + 后台工作台”的总体方向，但仍存在四类执行风险：

- 视频入口、视频专区和播放器被写成当前主导航能力，但 Cloudflare Stream 仍未接入。
- “高级、干净、有吸引力”等风格目标缺少可测量的页面级验收标准。
- 组件清单缺少 loading、empty、error、disabled、locked、hover、focus、mobile 等状态矩阵。
- 响应式和可访问性要求偏原则化，缺少断点、键盘、焦点、弹窗和对比度的检查方法。

本次整改目标是把 UI 设计文档从“风格描述”推进为“可验收的设计规格”，同时保持前台和后台的不同气质：前台像可信的写真杂志橱窗，后台像安静高效的运营工作台。

## 2. UI 质量标准

新增或修改 UI 需求时必须满足以下标准：

- 每个页面必须标注当前状态：`已上线`、`部分实现`、`规划`、`废弃`。
- 每个核心页面必须覆盖默认、加载、空状态、错误、权限不足和移动端状态。
- 任何视频 UI 必须标注 `Stream 接入后启用`，当前不得作为上线阻断项。
- 所有图标优先使用 lucide 图标名，不使用 emoji 作为正式 UI 图标。
- 所有固定、浮动、弹窗、底部导航元素必须在 360px、768px、1024px 和 1440px 视口下确认不遮挡关键内容。
- 前台视觉可以精致，但不得使用露骨、擦边、暗示性文案或让会员 CTA 遮挡人物主体。
- 后台视觉必须服务操作效率，不使用前台式杂志装饰、强动效或低信息密度卡片堆叠。

## 3. UI 状态矩阵

| 页面/能力 | 当前状态 | 当前验收口径 | 后续补齐项 |
|-----------|----------|--------------|------------|
| 首页 | 已上线/持续优化 | 推荐、最新、标签、真实案例、规则入口和联系入口可用；无可播放视频时隐藏视频专区 | Stream 接入后再启用视频专区和视频角标 |
| 发现/搜索 | 已上线/持续优化 | 标签筛选、组合条件、搜索结果和无结果状态清晰；移动端无横向溢出 | 补充搜索建议动效和压测后的筛选响应指标 |
| 图库详情 | 已上线/持续优化 | 封面、标签、图片网格、锁定提示、会员引导和相关推荐清晰；未授权用户不看到真实私有地址 | Stream 接入后补充视频播放器、试看和完整视频锁定状态 |
| 登录/注册 | 已上线 | 支持用户名/邮箱登录、用户名注册、Turnstile 可见；错误提示明确 | 邮箱验证开启状态下补充验证码流程 UI 验收 |
| 用户中心/设置 | 已上线 | 账号信息、会员状态、个人设置、联系方式入口可用；移动端表单不溢出 | 补充头像上传失败、邮箱冲突、验证码过期等异常 UI |
| 真实案例 | 已上线 | `/cases` 和 `/cases/:slug` 公开可访问；图片高级、可信、无隐私泄露 | 补充图片放大浏览的键盘和移动手势验收 |
| 后台工作台 | 已上线/持续优化 | 统计、表格、筛选、批量操作、审计和设置入口高密度可扫读 | 补充 Owner/Admin 权限差异的 UI 禁用/隐藏规范 |
| zip 导入 UI | 部分实现 | 上传入口、任务记录、校验错误和任务状态可展示 | 完整异步导入、错误报告下载和失败项重试 UI |
| 视频 UI | 规划 | 当前隐藏或显示维护提示；不展示可点击完整视频播放入口 | Stream 接入后补充播放器、编码状态、签名播放和成本提示 |

## 4. 页面级验收清单

### 4.1 全站前台

- 360px 宽度下无横向滚动，固定底部 Tab Bar 不遮挡浮动联系入口、规则入口或主要 CTA。
- 页面首屏必须露出至少一个核心内容信号：封面图、标签导航、搜索入口或会员状态，不只展示空白装饰。
- 图片主体不得被 VIP/SVIP/锁定角标遮挡；角标应靠边且最大不超过卡片短边的 18%。
- 所有卡片标题移动端最多两行截断，桌面端默认一到两行截断，不能撑高网格造成瀑布错位。
- 空状态必须提供下一步动作，例如热门标签、返回首页、联系站长或重新搜索。

### 4.2 首页

- 桌面端推荐区、标签导航、真实案例和最新图库之间有清晰分区标题和视觉节奏。
- 移动端首屏不同时堆叠多个强 CTA，避免封面、标签、规则入口和联系入口互相遮挡。
- 首页不使用无限加载导致底部不可达；使用分页、有限批次加载或“查看更多图库”跳转。
- 首页广告位在后台提供实时预览，输入链接、文案和排期后，管理员无需切换前台即可检查展示效果和安全回退文案。
- 首页广告位前台和后台预览必须使用同一套文案、链接和排期清洗规则；在 360px、768px、1024px、1440px 视口下广告标题、摘要和按钮不横向溢出。
- 后台广告预览遇到不安全链接、超长文案或控制字符时，必须明确提示哪些值已按安全规则回退或清空，提示需对辅助技术可感知。
- 无可播放视频时不展示视频导航、视频专区和视频播放按钮。

### 4.3 图库详情

- 锁定内容必须同时用图标、文字和视觉遮罩表达，不只依赖颜色。
- 未登录、等级不足、会员过期和资源加载失败必须有不同文案。
- 图片网格在 360px 为 2 列，1024px 以上为 3 列或更高，但不得出现高度跳动导致按钮错位。
- 相关推荐在移动端不得挤压正文，需位于图片和会员引导之后。

### 4.4 后台

- 表格列在 1024px 宽度下仍能显示核心字段：标题、状态、等级、更新时间和主要操作。
- 批量操作必须有选中数量、二次确认、执行中 loading、成功/失败数量和失败原因。
- Owner-only 操作对 Admin 必须隐藏或禁用，并提供不可操作原因。
- 上传区必须展示限制、进度、失败原因和重试入口。
- 后台弹窗必须有明确标题、取消、确认、loading 和错误状态。

## 5. 组件状态矩阵

| 组件 | 必备状态 | 验收重点 |
|------|----------|----------|
| `GalleryCard` | default、hover、loading、empty image、locked、VIP/SVIP、mobile | 图片比例稳定，角标不遮挡主体，标题不撑破卡片 |
| `GalleryGrid` | loading、empty、error、pagination、mobile | 网格列数稳定，分页或查看更多入口可达 |
| `TagChip` | default、selected、removable、disabled、overflow | 触控目标不小于 44px，横向滚动有渐隐提示 |
| `SearchInput` | idle、focus、typing、suggestions、empty、error | focus ring 可见，建议项不遮挡键盘和底部导航 |
| `MediaLock` | login required、rank insufficient、expired、loading、error | 文案区分权限原因，不暴露真实资源地址 |
| `FloatingContactPanel` | collapsed、expanded、copied、qr expanded、external link、mobile | 浮层不超出视口，内部滚动不裁切二维码 |
| `FloatingRulesPanel` | collapsed、modal、disabled、rich text、external link | 富文本可读，外链有提示，关闭时不占位 |
| `CaseCarousel` | loading、empty、single item、multi image、mobile swipe | 图片比例统一，滑动不误触联系入口 |
| `AdminDataTable` | loading、empty、filtered empty、error、selected、bulk action | 行高稳定，批量栏不遮挡表头 |
| `ImportUploader` | idle、dragover、uploading、validating、partial failed、failed | 显示限制、进度、失败原因和下一步 |

## 6. 响应式验收

| 视口 | 验收要求 |
|------|----------|
| 360 x 740 | 无横向滚动；底部 Tab Bar 与双悬浮入口不重叠；图库卡片 2 列；表单按钮文字不换出按钮 |
| 768 x 1024 | 平板可使用 3 列网格；筛选条横向滚动有边缘渐隐；后台侧栏可折叠 |
| 1024 x 768 | 后台表格可扫读；前台顶部导航、搜索框和头像不拥挤 |
| 1440 x 900 | 前台内容最大宽度受控，卡片不过度拉伸；后台信息密度不降低 |

## 7. 可访问性验收

- Lighthouse Accessibility 目标 >= 90；核心页面包括 `/`、`/search`、`/galleries/:slug`、`/cases`、`/login`、`/settings`、`/admin`。
- 所有交互控件必须有可见 focus 状态，键盘 Tab 顺序与视觉顺序一致。
- 弹窗必须支持 Esc 关闭、焦点锁定和关闭后返回触发按钮。
- 图片 alt 规则：图库封面使用图库标题，真实案例图片使用案例标题 + 序号，装饰图使用空 alt。
- 颜色对比满足 WCAG AA，黑金、浅奶油、灰色标签组合必须抽样检查。
- 动效必须尊重 `prefers-reduced-motion`，禁用非必要位移和呼吸动画。

## 8. 线框图与资产留存

- `.superpowers/brainstorm/` 中未纳入版本管理的线框图不可作为长期唯一依据。
- 关键线框图应导出到 `docs/ui/wireframes/` 或以截图形式记录，至少保留首页、图库详情、搜索、用户中心和后台工作台。
- 线框图更新时需要记录日期、适用版本和与 `docs/UI_DESIGN.md` 的差异。
