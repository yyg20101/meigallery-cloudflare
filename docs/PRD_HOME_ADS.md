# 首页广告位 PRD

## 1. 执行摘要

- **问题陈述**：首页首屏已有精选内容和真实案例，但缺少一个可快速调整的运营推荐位，站长无法在不改代码的情况下突出阶段性活动、会员内容或赞助推荐。
- **解决方案**：新增独立后台广告位管理页，支持首页多个广告的启停、排序、排期、大图上传和轮播展示；广告展示在首页首屏之后、真实案例之前，支持中文文案、CTA、站内链接和 `https://` 外链。
- **成功标准**：
  - 站长可在后台 `/admin/ads` 完成新增、编辑、启用、停用、排序、大图上传/删除和开始/结束时间设置，保存后公开设置接口返回过滤后的 `home_ads` 数组。
  - 首页广告位无有效广告、未到开始时间或已到结束时间时不渲染任何占位，生效时在 360px、768px、1024px、1440px 视口下不遮挡首屏内容。
  - 多条有效广告按后台排序轮播，并提供手动圆点切换；单条广告不启动轮播。
  - 广告链接只允许显式解析通过的公开前台相对路径或 `https://` 外链；拒绝 `javascript:`、`data:`、`http://`、协议相对链接、空白控制字符、编码控制字符、反斜杠路径、后台/API/资源路径和包含用户名或密码的链接。
  - 广告大图只允许上传到 R2 的 `/api/media/public/home-ads/` 路径或安全 `https://` 图片地址；图片加载使用 `referrerpolicy="no-referrer"`。
  - 外链在新窗口打开，并使用 `rel="noopener noreferrer nofollow sponsored"` 和 `referrerpolicy="no-referrer"`；前台广告位需要向用户提示该 CTA 为外部链接且不会发送来源页信息。
  - 后台广告设置写操作进入 `admin_audit_logs` 审计日志。

## 2. 用户体验与功能

- **用户画像**：
  - 站长：需要临时推荐会员内容、活动合集或赞助合作链接。
  - 游客/会员：在首页浏览时看到一条轻量推荐，不影响图库和真实案例浏览。

- **用户故事**：
  - 作为站长，我希望在独立后台页面配置多个首页广告、调整顺序和展示时间窗，以便提前准备阶段性运营推荐。
  - 作为站长，我希望给广告上传大图，以便首页推荐位比普通文字提示更醒目。
  - 作为访客，我希望只在广告有效期内看到明确的推荐标题和跳转按钮，以便进入相关内容或活动页。
  - 作为安全维护者，我希望限制广告链接协议，以便首页不会成为 XSS 或不安全跳转入口。

- **验收标准**：
  - 后台广告位管理页包含广告列表、排序操作、启停操作、删除确认、广告表单、图片上传/删除和首页预览。
  - 广告表单包含眉标、标题、摘要、按钮文案、链接、赞助/来源说明、大图 URL、开始时间和结束时间。
  - 开始/结束时间留空表示不限制；非空值保存为 UTC ISO 字符串，结束时间必须晚于开始时间。
  - 新广告位默认启用；站长可手动停用。旧 `home_ad_*` 单广告配置仅作为兼容兜底，不再作为主要配置入口。
  - 公开设置接口只返回白名单中的广告字段，且过滤停用、过期、不安全链接或标题异常的广告。
  - 首页优先按 `home_ads` 数组渲染轮播；当 `home_ads` 为空时，才使用旧 `home_ad_active` / `home_ad_*` 兼容配置。
  - 首页 SEO 标题、描述和 OG 信息必须读取后台站点设置；后台修改后首页不得继续覆盖为硬编码默认标题。
  - 首页组件不使用 HTML 注入，仅渲染纯文本和安全图片地址。
  - 单元测试覆盖广告 payload 校验、链接校验、大图 URL 校验、排期归一化、后台创建/排序/删除、公开读取清洗和前端轮播/链接渲染。

- **非目标**：
  - 首期不接入第三方广告 SDK 或实时竞价广告。
  - 首期不实现广告曝光/点击统计。
  - 首期不实现按会员等级、地区或标签定向投放。

## 3. AI 系统要求

本功能不包含 AI 系统。

## 4. 技术规格

- **架构概览**：
  - D1 migration `0022_home_ads.sql` 新增 `home_ads` 表，字段包含位置、文案、CTA、跳转链接、来源说明、大图 URL/R2 key、启停、排期和排序。
  - API 新增 Owner 专用 `/api/admin/ads` 路由，负责列表、创建、更新、删除、排序和大图上传/删除；所有写操作记录 `admin_audit_logs`。
  - `/api/settings/public` 同时读取 `site_settings` 和 `home_ads`，返回过滤后的 `home_ads` 数组，并继续保留旧 `home_ad_*` 公开字段作为兼容兜底。
  - Web `useSiteSettings()` 提供 `homeAds` computed，首页优先把多广告数组传给 `HomeAdBand`，旧单广告仅在新广告为空时回退。
  - `HomeAdBand` 支持大图横幅、多广告自动轮播、圆点切换、预览模式和站内/外链安全提示。

- **集成点**：
  - D1：`home_ads`、`site_settings`、`admin_audit_logs`。
  - R2：`home-ads/{adId}/{imageId}.{ext}`。
  - API：`/api/admin/ads`、`/api/settings/public`、`/api/media/public/home-ads/*`。
  - Web：首页 `/`、后台 `/admin/ads`、后台设置页 `/admin/settings` 的迁移入口。

- **安全与隐私**：
  - 广告链接只允许显式解析通过的公开前台相对路径或 `https://`，并拒绝空白控制字符、编码控制字符、反斜杠路径、后台/API/资源路径和包含用户名或密码的链接。
  - 广告大图 URL 只允许 `/api/media/public/home-ads/` 或安全 `https://`；上传大图删除旧图前必须校验 R2 key 属于当前广告。
  - 排期字段只接受可解析时间并统一为 ISO 字符串；历史异常排期不会触发广告展示。
  - 外链使用新窗口并加 `noopener noreferrer nofollow sponsored` 和 `referrerpolicy="no-referrer"`，同时展示离站提示，避免访客误以为赞助链接仍是站内页面。
  - 文案按 Vue 默认转义纯文本渲染，不执行 HTML。
  - 后台写操作继续要求 Owner 权限并记录审计日志。

## 5. 风险与路线图

- **阶段发布**：
  - MVP：独立广告位管理、多广告排序、大图上传和首页轮播。
  - v1.1：补充点击统计和展示次数统计，但不得引入第三方追踪脚本作为默认行为。
  - v1.2：支持按会员等级、地区或标签定向展示不同广告。
  - v2.0：评估第三方广告合作能力；若涉及脚本、Cookie 或跨站追踪，需另行合规评审。

- **技术风险**：
  - 外链配置错误可能影响用户信任，已通过协议白名单和安全属性降低风险。
  - 排期配置错误可能导致广告提前展示或过期未隐藏，已通过后台顺序校验和公开设置过滤降低风险。
  - 大图版权或外链图床稳定性可能影响用户体验，上传入口限制文件类型/大小，外链仅允许安全 `https://`。
  - 后续若接入第三方广告脚本，需单独进行隐私、CSP、Cookie 和合规评审。
