# PRD 质量审阅与整改清单

更新时间：2026-05-26

本文用于约束 `docs/PRD*.md` 的需求质量。若历史 PRD 与当前实现状态冲突，以 `docs/PROJECT_STATUS.md`、`AGENTS.md`、`docs/TECHNICAL_SPEC.md` 和本文的状态矩阵为准。

## 1. 审阅结论

现有 PRD 已覆盖主要产品方向、用户故事和技术路线，但存在三类质量问题：

- 当前已上线能力、部分实现能力和后续规划能力混在同一验收范围中，容易误判上线阻断项。
- 部分指标有目标值但缺少测试方法、测试数据集、角色权限和失败路径定义。
- 视频、邮箱、批量导入、旧站审核等依赖外部服务或异步任务的能力，需要更明确的分阶段验收口径。

本次整改不重写全部 PRD，而是建立统一状态矩阵，并修正主 PRD 与专题 PRD 中会影响执行判断的冲突表述。

## 2. PRD 质量标准

新增或修改需求时必须满足以下标准：

- 每个功能必须标注状态：`已上线`、`部分实现`、`规划`、`废弃`。
- 每条验收标准必须至少包含触发条件、输入、输出、权限要求和失败处理中的三项。
- 性能或成功率指标必须说明测试环境、数据规模、采样方法和是否作为当前上线阻断项。
- 涉及 Cloudflare Stream、Email Service、Workers 限制、价格或配额的内容，实施前必须重新核对官方文档和 Dashboard 当前状态。
- 历史 PRD 的非目标若已被后续 PRD 覆盖，必须显式标注“本 PRD 不实现，由后续 PRD 管理”。
- 安全、权限、审计和内容合规要求不得只写原则，必须落到字段、状态、日志或发布前 checklist。

## 4. 验收标准补齐清单

### 4.1 性能指标

- Lighthouse 指标必须指定页面：`/`、`/search`、`/galleries/:slug`、`/login`、`/settings`。
- Lighthouse 测试需分别记录移动端和桌面端结果；首发阻断口径为核心页面 Performance >= 85，Accessibility >= 90。
- 搜索 P95 指标需使用脚本生成数据集，至少包含图库总量、标签分布、关键词命中率和冷/热缓存说明。
- 10 万图库规模搜索指标属于扩展压测目标，不阻断当前旧站规模上线。

### 4.2 批量导入

当前可验收：

- zip 包包含 `manifest.csv`、每个目录包含 `content.md`、`cover.jpg` 和至少一张图片时，系统创建导入任务。
- 非法字段、缺失文件、重复 slug 和不支持的文件类型会返回结构化错误。
- 单个图库失败时，任务保留失败条目，不影响其他条目的校验结果。

后续完整验收：

- 100 个合法图库目录中，任务完成后至少 98 个创建草稿图库、媒体记录和封面记录。
- 每个失败项必须包含 `folder`、`file`、`code`、`message` 和可操作建议。
- R2 上传失败、D1 写入失败和标签自动创建失败必须分别可重试。

### 4.3 内容审核与合规

发布前必须满足：

- 图库或真实案例有明确授权来源记录，字段可为空的历史数据必须进入待审核。
- 审核记录包含审核人、审核时间、审核结论和备注。
- 待审核原因至少包含：敏感词命中、缺少媒体、媒体下载失败、授权状态未知、年龄或隐私风险。
- Owner/Admin 发布时必须确认合规 checklist；未确认时 API 返回 400 或 403。

建议审核状态机：

| 状态 | 进入条件 | 可执行操作 |
|------|----------|------------|
| `pending_review` | 旧站迁移、导入异常、授权未知或敏感词命中 | 编辑、补充授权、提交审核 |
| `needs_media_fix` | 缺少封面、图片下载失败或媒体记录不完整 | 补传媒体、重试迁移 |
| `approved` | 授权和内容 checklist 通过 | 发布 |
| `rejected` | 侵权、隐私、年龄或内容边界不符合 | 归档或删除 |

### 4.4 邮箱功能

默认关闭状态验收：

- `email_verification_enabled=false` 时，注册和修改邮箱不依赖 Email Service。
- 邮箱服务未配置时，不影响登录、注册、用户中心和后台管理主流程。

开启状态验收：

- 验证码 10 分钟有效，3 次错误后作废。
- 同一邮箱 60 秒内不可重复发送，同一 IP 每小时最多 10 次发送请求。
- 送达率和 30 秒到达率只在 Email Service、DNS、发件域名配置完成后作为验收项。

### 4.5 视频功能

当前验收：

- Stream 未接入时，前台不展示可点击的完整视频播放入口。
- API 不返回无效 Stream UID、未签名播放地址或私有占位 secret。
- 迁移发现的视频 URL 可记录为待处理元数据，但不得标记为已可播放。

Stream 接入后验收：

- 上传使用 Stream direct upload 或 TUS，视频文件不经过 API Worker 请求体。
- 编码完成后写入 `stream_uid`，失败时记录可重试状态。
- 会员视频播放必须通过服务端校验 rank 后签发短期播放 token。
- 运营看板记录播放分钟数和错误率。

## 5. 后续文档任务

- 持续维护主 PRD 的“当前上线阻断”和“后续压测目标”分层，新增指标时必须说明验收环境。
- 为 zip 批量导入补充完整异步任务 PRD 或技术设计。
- 为内容审核补充字段设计和后台交互验收。
- Stream 接入前新增单独 PRD，避免视频规划继续污染当前上线验收。
- Email Service 开启前新增部署验收清单，覆盖 DNS、费用、额度和退订策略。
