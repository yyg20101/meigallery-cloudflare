# UI 设计初稿

## 1. 设计目标

- 面向手机端和网页端，优先保证浏览效率、图片展示质量和搜索筛选体验。
- 视觉应克制、清爽、内容优先，避免低质猎奇感。
- 后台应偏工作台风格，信息密度高，操作路径短。

## 2. 前台页面

首页:

- 顶部导航：Logo、搜索、标签入口、登录/用户中心。
- 首屏：精选图库和视频入口。
- 内容区：最新图库、热门地区、热门性格、视频专区。
- 移动端：底部导航可包含首页、分类、搜索、我的。

图库列表:

- 顶部筛选条：地区范围、城市/国家、身份、性格、风格、内容类型。
- 卡片：封面、标题、标签、会员标识、视频标识。
- 移动端采用双列瀑布或规则网格，避免文本遮挡图片。

详情页:

- 顶部：标题、摘要、标签。
- 主内容：图片浏览、视频试看、完整视频锁定区域。
- 侧边或底部：相关推荐、联系站长提示。
- 锁定内容使用清楚的权限提示，不展示真实资源地址。

用户中心:

- 会员等级、到期时间、权益说明。
- 站长联系方式。
- 收藏和浏览历史可放入 v1.1。

## 3. 后台页面

后台首页:

- 数据概览：图库数、已发布、草稿、导入任务、会员数。
- 待处理事项：失败导入、待审核草稿、即将到期会员。

图库管理:

- 表格列：封面、标题、状态、所需等级、标签、发布时间、更新时间。
- 操作：编辑、预览、发布、下架、归档。
- 批量操作：批量设置标签、批量下架、批量修改等级。

导入任务:

- 上传入口。
- 任务列表：状态、上传者、总数、成功数、失败数、创建时间。
- 详情页展示每个目录的校验结果。

旧站迁移:

- 来源配置：旧站 URL、REST API/XML 模式、分类映射、标签映射。
- 迁移任务列表：状态、文章总数、成功数、失败数、待审核数。
- 迁移预览：旧标题、旧分类、旧标签、新标签、媒体列表、风险提示。
- 批量审核：通过、退回、改标签、改标题、删除敏感文案。

会员管理:

- 用户搜索。
- 当前等级和有效期。
- 发放等级表单。
- 历史发放记录。

## 5. 响应式断点

- Mobile: 360 px - 767 px。
- Tablet: 768 px - 1023 px。
- Desktop: >= 1024 px。

## 6. 可访问性要求

- 所有按钮和表单控件必须有明确 label。
- 图片必须有 alt 文本，装饰图可为空 alt。
- 锁定内容不能只用颜色表达状态。
- 移动端点击目标不小于 44 px。
- 键盘可访问后台核心操作。

## 7. 视觉方向

- 内容前台：白底或浅灰底，重点突出图片本身。
- 会员标识：使用小型 badge，不要覆盖主体画面。
- 后台：中性色、明确表格、固定操作区域。
- 避免夸张渐变、过度装饰和营销式大段说明。
- 旧站迁移和审核界面要突出风险状态，不要把敏感词作为前台视觉卖点。
