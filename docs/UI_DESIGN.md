# UI 设计规范

当前 UI 质量验收和状态矩阵见 `docs/UI_QUALITY_REVIEW.md`。若本文中的历史规划与当前实现状态冲突，以 `docs/PROJECT_STATUS.md`、`docs/PRD_QUALITY_REVIEW.md` 和 `docs/UI_QUALITY_REVIEW.md` 为准。

## 1. 设计目标

- 面向手机端和网页端，优先保证浏览效率、图片展示质量和搜索筛选体验。
- 站点内容重点为女性写真、时尚、生活、艺术类图库，视觉应高级、干净、有吸引力，避免低质猎奇感或露骨化表达。
- 前台以图片和人物气质为主视觉，强化“写真杂志”的浏览沉浸感和会员转化效率。
- 后台应偏工作台风格，信息密度高，操作路径短。
- UI 验收必须覆盖默认、加载、空状态、错误、权限不足、移动端和键盘可访问状态。

### 1.1 页面级完成定义

- 核心页面在 360px、768px、1024px、1440px 四个视口下无横向滚动和明显遮挡。
- 前台首屏必须露出至少一个核心内容信号：封面图、标签导航、搜索入口、真实案例或会员状态。
- 图片主体不得被 VIP/SVIP/锁定角标、浮层或 CTA 遮挡；角标应靠边且最大不超过卡片短边的 18%。
- 空状态、加载状态、错误状态必须提供下一步动作，不显示技术堆栈或原始异常。
- Lighthouse Accessibility 目标 >= 90；核心页面包括 `/`、`/search`、`/galleries/:slug`、`/cases`、`/login`、`/settings`、`/admin`。

## 2. 视觉风格

**珍珠杂志感** — 白底留白、奶油肤色系、黑金点缀、柔和阴影、精致排版，强调女性写真内容的高级感和浏览发现感。

核心视觉特征：
- 白底/浅灰底，大量留白
- 图片是主视觉元素，文字辅助
- 标签和分类清晰可见，方便浏览发现
- 类似高端写真杂志、时尚画册或精品影像目录的精致排版感
- 使用柔和的浅色背景、奶油肤色点缀和少量黑金强调，避免大面积高饱和粉紫渐变
- 交互反馈应轻、准、细：卡片轻微上浮、图片柔和放大、浮层有层次但不喧宾夺主

配色体系：
- 主色：#111111（文字/主按钮/当前选中）
- 背景：#FFFFFF / #FAFAFA / #F8FAFC / #FFFBF7（珍珠暖白）
- 边框：#E5E7EB / #F0F0F0
- 珍珠暖色：#FFF7ED / #F8E7DC / #E8D5C5（背景、柔和分区、悬浮层点缀）
- 黑金强调：#111111 / #BFA46A / #D6C39A（主按钮、VIP、关键 CTA）
- VIP 标识：#EAB308（金色）
- SVIP 标识：#7C3AED（紫色）
- 免费标识：#22C55E（绿色）
- 错误/告警：#EF4444 / #991B1B
- 标签背景：#F3F4F6，圆角 pill 样式

颜色使用约束：
- 珍珠暖白和浅灰承担背景层次，不应让整页变成单一奶油色。
- 金色只用于 VIP、会员权益、精选和关键 CTA，单屏内不应超过 3 个强金色视觉点。
- SVIP 紫色仅作为状态标识，不作为大面积主背景。
- 正文、按钮、标签和状态色必须满足 WCAG AA 对比度要求。

### 2.1 珍珠杂志感实施原则

- **前台优先图片质感**：任何装饰、边框、阴影都不能抢过封面图；装饰只能用于提升层次。
- **美女写真但不低俗**：文案使用“写真、精选、风格、气质、会员权益”等表达，不使用露骨、擦边或暗示性用词。
- **浅色主场景**：全站默认白底/暖白底，深色仅用于按钮、视频、会员重点 CTA 或局部浮层。
- **黑金只做强调**：金色用于 VIP、会员权益、精选角标等关键转化点，避免泛滥。
- **圆角与阴影更精致**：前台卡片圆角可提升到 10-18px，浮层和弹窗圆角 20-28px，阴影使用低透明度大扩散。
- **动效克制但可感知**：hover 上浮 2-4px、图片缩放 1.02-1.04、浮层进入 150-220ms，避免跳动和复杂动画。

## 3. 首页布局

**分区块流式布局** — 每个区块有独立标题和横向滚动卡片，杂志感最强。

### 桌面端（≥1024px）

结构（自上而下）：
1. 顶部导航栏：Logo | 主导航（首页/发现/标签，视频入口仅在 Stream 接入且存在可播放视频时展示）| 搜索框 | 登录按钮，导航背景采用半透明白 + 轻微模糊，滚动时保持清爽悬浮感；不展示“关于”入口
2. 精选轮播区：大封面叙事布局，仅保留标题、摘要和封面视觉，去除“浏览精选图库”和“地区精选”两个按钮
3. 标签导航区：城市/地区优先，辅以风格、身份、场景分组，使用更明显的分区标题和黑金选中态
4. 首页广告位：默认关闭；开启后展示在精选轮播和真实案例之间，采用横向运营胶片条，不抢占首屏主体，只渲染纯文本，外链必须安全跳转
5. 真实案例轮播：替代原“按地区发现”，展示用户好评案例图片组，采用大图 + 横向缩略图或多卡片走马灯
6. 最新图库：4 列等宽网格，封面+标题+标签，VIP/SVIP 角标；视频角标仅在 Stream 接入后展示；首页不再无限加载到底部不可达
7. 视频专区：Stream 未接入或无可播放视频时隐藏；接入后使用暗色调 3 列等宽卡片，播放按钮居中，图标使用 lucide `Play`
8. 双悬浮入口：右下角规则/引导入口在上，联系站长消息入口在下

### 移动端（360-767px）

结构（自上而下）：
1. 顶部栏：Logo | 搜索图标 | 头像
2. 精选轮播：单张强封面优先，去除双按钮，避免首屏拥挤
3. 标签导航：优先展示热门城市和地区组，横向滚动时保留边缘渐隐提示
4. 首页广告位：开启时以单列横向运营条呈现，按钮不换行溢出；关闭时不占位
5. 真实案例：可滑动用户好评案例卡片，每张卡片展示 1 张主图和图片数量提示
6. 最新图库：2 列规则网格，底部使用“查看更多”入口或分页，不使用持续无限加载
7. 底部 Tab Bar（固定）
8. 双悬浮入口：底部 Tab Bar 上方右侧垂直堆叠，规则入口在上，联系站长消息入口在下

## 4. 导航系统

### 桌面端

顶部固定导航栏：
- 左：Logo（品牌名 MeiGallery）
- 中：主导航 tabs（首页/发现/标签；视频入口仅在 Stream 接入且存在可播放视频时展示），当前页下划线高亮；不再展示“关于”入口
- 右：搜索输入框 + 登录按钮（未登录）/ 头像下拉（已登录）
- 质感：默认白底半透明，边框使用 #F0F0F0；滚动时可增强阴影或模糊，保持轻盈。
- 交互：导航项 hover 使用文字变深 + 下划线/底部边框过渡，不使用大色块。

### 移动端

底部固定 Tab Bar，4 个入口，图标使用 lucide：
| Tab | lucide 图标 | 说明 |
|-----|-------------|------|
| 首页 | `Home` | 推荐+最新内容流 |
| 发现 | `Tags` | 标签分类筛选 |
| 搜索 | `Search` | 全屏沉浸式搜索 |
| 我的 | `User` | 用户中心/登录入口 |

当前选中 Tab：文字加粗 + 颜色 #111。

### 常驻联系方式入口

- 形式：固定浮动消息 icon，桌面端位于右下角，移动端位于底部 Tab Bar 上方，与规则入口垂直堆叠。
- 默认态：圆形或小胶囊消息按钮，包含聊天气泡图标、未读红点和“有新消息”短提示，模拟站长有新消息待查看。
- 动效：消息 icon 可轻微跳动或呼吸，周期不短于 4 秒，hover 或首次进入时增强一次，避免廉价抖动。
- 展开态：圆角 24-28px 的白色/暖白浮层，包含标题、说明、多联系方式列表和底部提示。
- 多联系方式：列表区域最大高度不超过视口 45%，超过后内部滚动。
- 二维码：在联系方式条目内联展开，避免被浮层滚动容器裁切。
- 无跳转链接：点击复制联系值，显示“已复制”即时反馈。
- 有跳转链接：使用外链图标提示，打开新窗口。
- 使用图标：消息入口使用 lucide `MessageCircle`，复制使用 `Copy`，成功使用 `Check`，外链使用 `ExternalLink`，二维码使用 `QrCode`。

### 常驻规则/引导入口

- 形式：固定浮动入口，位于联系站长入口上方，视觉比联系入口更安静，避免抢夺主 CTA。
- 默认态：可使用“规则”“说明”“入站指南”等中文短文案，搭配 lucide `FileText`、`Info` 或 `ShieldCheck` 图标。
- 点击行为：默认打开弹窗，弹窗展示后台配置的富文本摘要，并提供“查看完整规则”跳转至规则页。
- 弹窗视觉：珍珠暖白背景、黑金标题、正文 13-14px，支持短段落、列表、链接和重点提示。
- 后台配置：标题、短说明、图标、富文本内容、规则页链接、启用状态均应可配置。
- 安全要求：富文本必须经过白名单清洗，外链必须明确提示并使用安全跳转属性。

## 5. 前台页面详细设计

### 5.1 图库详情页

**桌面端 — 双栏布局**：
- 左栏（flex:3）：封面大图 → 标题/标签/元信息 → 摘要 → 公开图片网格（3列）→ 锁定图片区；视频区仅在 Stream 接入后展示预览和完整锁定状态
- 右栏（flex:1）：会员引导卡 → 相关推荐列表；联系方式由全局浮动入口承担，不在详情右栏重复出现。
- 封面区：可使用更大的圆角、柔和阴影和轻微暖色背景，突出写真封面质感。

**移动端 — 单栏流式**：
- 返回按钮+标题 → 全宽封面 → 标签/元信息 → 摘要 → 图片（2列） → 锁定提示 → 会员引导 → 相关推荐（2列）；视频模块仅在 Stream 接入后插入；联系方式由底部浮动入口常驻展示。

**权限提示设计**：
- 锁定内容：dashed border + 半透明灰色遮罩（opacity:0.3）
- 明确文案：使用 lucide `Lock` 图标 +「剩余 N 张图片需要 VIP/SVIP 会员」
- CTA 按钮：实心黑色圆角按钮「了解会员权益」
- 视频锁定：Stream 接入后使用暗色背景 + `Lock` 图标 + 等级文案

**相关推荐**：
- 桌面端：右栏垂直列表，缩略图+标题+标签
- 移动端：底部 2 列小卡片

### 5.2 发现/浏览页

**筛选交互**：
- 顶部标签类型 Tab 栏：地区 | 身份 | 性格 | 风格 | 职业 | 场景 | 内容类型
- 选中类型后下方展开子标签 pill 列表
- 已选标签显示为彩色可移除 chip（蓝色/粉色等区分类型）
- 支持多标签组合筛选（AND 逻辑）
- URL 同步：`/discover?region=guangdong&personality=sweet`
- 珍珠杂志感升级：筛选栏采用暖白卡片底、细边框、横向滚动阴影提示；选中标签用黑底白字或黑金边框，避免过多彩色干扰封面。

**结果展示**：
- 排序选项：最新 | 最热 | 随机
- 结果统计：「共 N 个图库」
- 桌面端 4 列网格，移动端 2 列网格
- 底部分页导航

### 5.3 搜索页

**移动端为沉浸式全屏搜索**：
- 聚焦搜索框 + 返回按钮 + 搜索按钮
- 输入时实时显示搜索建议（标题匹配高亮）
- 搜索结果上方推荐相关标签（蓝色 pill，可点击添加筛选）
- 排序：综合 | 最新 | 最热
- 搜索输入框应使用更明显的 focus ring 和柔和阴影，输入后建议项使用 stagger 淡入，提升“即时响应”感。

**无结果状态**：
- 大搜索图标 + 「没有找到相关内容」
- 引导文案 + 热门标签推荐

### 5.4 登录/注册页

**设计原则**：
- 极简居中卡片式布局
- Logo + slogan 在表单上方
- Turnstile 组件必须可见

**登录表单**：
- 用户名 / 邮箱输入框
- 密码输入框（右侧「忘记密码？」链接，v1.1）
- Turnstile 人机验证区域
- 登录按钮（实心黑色，全宽）
- 底部：「还没有账号？立即注册」

**注册表单**：
- 用户名 + 邮箱 + 密码 + 确认密码
- Turnstile 验证
- 注册按钮
- 底部：「已有账号？立即登录」

### 5.5 用户中心

**用户信息区**：
- 头像（默认占位）+ 用户名 + 邮箱
- 头像占位使用暖灰/珍珠渐变背景，会员用户可叠加 VIP/SVIP 小角标。

**会员状态卡**：
- 渐变背景（VIP金色/SVIP紫色/免费灰色）
- 显示：当前等级（大字）、有效期至日期
- 底部权益一句话说明

**权益对比**：
- 三栏对比：免费 | VIP(当前高亮) | SVIP
- 列出各等级可访问的内容类型

**联系站长**：
- 用户中心不再单独插入联系方式卡片，由全局浮动入口常驻展示，避免与功能入口重复堆叠。

**功能入口**：
- 浏览历史（标注 v1.1）
- 我的收藏（标注 v1.1）
- 退出登录（红色文字）

### 5.6 首页真实案例与标签导航

**设计方向**：
- 使用 `frontend-design` 方法执行“珍珠杂志感 + 消息信笺式可信引导”，避免通用营销页套路。
- 首页应从“内容列表”转向“可信图库橱窗”：强封面、清晰标签、真实案例、轻量咨询入口共同形成浏览和转化路径。

**真实案例轮播**：
- 替代原“按地区发现”区块，标题建议为“真实案例”或“用户好评”。
- 桌面端：可采用 1 张大图 + 3-5 张缩略图的画廊式轮播，或 3 列案例卡片横向滑动；图片比例统一为 4:3 或 3:4，避免杂乱。
- 移动端：单卡片横向滑动，卡片底部显示案例标题、图片数量和简短说明。
- 每个案例支持多张图片，前台展示不超过 9 张；超过时显示“+N”叠层提示。
- 首页案例卡片点击进入真实案例详情页，区块标题右侧或底部提供“查看全部案例”进入列表页。
- 真实案例图片必须保持高级、可信、干净，不展示隐私信息、联系方式、付款凭证或未经授权截图。

**真实案例列表页**：
- 路由建议为 `/cases`，全部公开访问，不要求登录。
- 桌面端使用 3 列或 4 列杂志卡片网格，卡片包含主图、标题、简短说明、图片数量和发布时间。
- 移动端使用 1 列大卡或 2 列紧凑卡，优先保证标题可读和图片不拥挤。
- 顶部需要有返回首页、案例说明和联系站长入口，帮助用户从“看案例”过渡到“咨询”。
- 空状态使用暖白卡片和引导文案，不显示技术错误信息。

**真实案例详情页**：
- 路由建议为 `/cases/:slug`，全部公开访问，不要求登录。
- 桌面端采用“左侧大图画廊 + 右侧案例说明/联系入口”的双栏布局；移动端为单栏图文流。
- 图片组支持点击放大浏览，非首屏图片 lazy load；当前案例至少展示 2 张图片。
- 详情页底部提供“返回案例列表”“联系站长”“查看更多图库”三个路径，但避免过多按钮堆叠。
- 详情页 SEO 标题和描述应来自案例标题与说明，图片 alt 使用案例标题 + 序号。

**首页标签导航**：
- 标签导航必须比普通 pill 列表更突出，优先解决“想看具体城市但不方便找”的反馈。
- 桌面端建议使用三段式结构：热门城市、地区组、风格偏好；每组有标题、短说明和横向标签。
- 移动端建议使用“城市优先”的横向卡片，第一屏至少露出 4 个城市/地区入口。
- 选中态使用黑底白字或黑金描边，默认态使用暖白底 + 细边框，避免标签不明显。
- 标签入口点击后进入发现页或搜索页对应筛选结果，城市/地区点击路径不超过 2 次。

**首页底部**：
- 首页不再使用持续无限加载导致底部不可达的模式。
- 如需要继续浏览更多图库，使用“查看更多图库”按钮跳转发现页，或使用明确分页/有限批次加载。
- 旧底部元素可以删除，或重设计为简洁页脚：版权、规则入口、联系方式入口、内容合规说明。

**关于页处理**：
- 前台不再展示关于页面入口。
- 关于页面承载的信息应迁移至规则弹窗、规则页、页脚或站点设置说明中。

**Dev 测试环境标识**：
- Workers dev 子域页面必须显示测试环境标识，例如右上角小型“DEV 测试环境”角标。
- 测试环境标识不应遮挡真实案例、联系入口和图片查看器关键操作。
- dev 子域不进入主导航、页脚、sitemap 或公开链接。

- **技术栈**：Nuxt UI v4，CSR 模式（ssr:false）

导航项目：

### 6.2 Dashboard

**统计卡片行**（5列等宽）：
- 图库总数（含本周增量）
- 已发布数

- 会员用户数
- 导入任务数（含失败数）

**待处理事项**：
- 红色：失败的导入任务
- 黄色：待审核的草稿
- 绿色：即将到期的会员

**最近图库表格**：标题/状态/等级/标签/更新时间

### 6.3 图库管理列表

**工具栏**：页面标题 + 总数 badge | 搜索框 + 新建按钮

**批量操作栏**：全选 checkbox | 已选数 | 批量设标签 / 批量改等级 / 批量下架

**表格列**：checkbox | 封面缩略图 | 标题 | 状态(badge) | 所需等级 | 标签 | 媒体统计 | 更新时间 | 操作(编辑/预览/发布/下架)

**上传区域**：虚线边框拖拽区，支持点击上传，限制 2GB

**任务状态色**：

- 完成：绿色

### 6.5 后台工作台验收

- 1024px 宽度下，表格仍能展示核心字段：标题、状态、等级、更新时间和主要操作。
- 批量操作栏必须展示选中数量、二次确认、执行中 loading、成功/失败数量和失败原因。
- Owner-only 操作对 Admin 必须隐藏或禁用，并在禁用态提供不可操作原因。
- 上传区必须展示格式/大小限制、进度、失败原因和重试入口。
- 后台弹窗必须有明确标题、取消、确认、loading、错误和关闭后焦点回归状态。

## 7. 卡片设计规范

### GalleryCard

```
┌──────────────────┐
│  [封面图 16:9]   │  ← 圆角 10-14px，占满宽度
│         [VIP] ←──│  ← 右上角角标（金色/紫色；视频标记仅 Stream 接入后显示）
├──────────────────┤
│ 标题              │  ← 11-12px，font-weight:500，单行截断
│ [标签1] [标签2]   │  ← 9-10px，灰底圆角 pill
└──────────────────┘
```

珍珠杂志感细节：
- 卡片默认无重边框，使用轻微背景分层或透明边框。
- hover：整体上浮 2-4px，封面轻微放大 1.02-1.04，阴影增强但不发黑。
- 标题区保持克制，不使用大面积色块；标签以暖灰/浅奶油底为主。
- 精选/会员角标可以使用黑金组合，但尺寸要小，避免遮挡人物主体。

角标类型：
- VIP：金色背景 #EAB308 白字
- SVIP：紫色背景 #7C3AED 白字
- 视频：Stream 接入后使用半透明黑色背景 + lucide `Play` 图标
- 免费：不显示角标

### TagChip

- 默认：#F3F4F6 背景 + #333 文字，圆角 16px
- 选中：#111 背景 + #FFF 文字
- 可移除：彩色背景 + lucide `X` 按钮
- 珍珠杂志感：默认标签可使用 #F8E7DC / #F3F4F6，选中态优先黑底白字或黑金描边；避免整页出现过多高饱和颜色。

### FloatingContactPanel

- 入口：固定浮动消息 icon，黑底或暖白底均可，包含未读红点、消息气泡图标和短提示。
- 展开：白色/暖白浮层，圆角 24-28px，阴影 `0 24px 60px rgba(15,23,42,.10-.16)`。
- 列表：支持多个联系方式，超过高度后内部滚动；每项保留平台图标、标签、联系值/外链/二维码提示。
- 状态：复制成功显示“已复制”；二维码点击后在当前项下方展开；外链项显示外链图标。
- 响应式：移动端固定在底部 Tab Bar 上方，桌面端固定在右下角。

### FloatingRulesPanel

- 入口：固定在联系站长入口上方，展示规则/说明/入站指南等短文案。
- 弹窗：显示后台配置的富文本摘要，底部可跳转规则页。
- 状态：支持启用/关闭；关闭时不占位，不影响联系入口位置。

### CaseCarousel

- 用途：首页真实案例轮播，展示用户好评案例图片组。
- 桌面端：画廊式布局或横向多卡片轮播。
- 移动端：单卡片滑动，显示图片数量和简短说明。
- 加载：首张图可优先加载，其余图片 lazy load。

### CaseCard

- 用途：真实案例列表页卡片，展示主图、标题、说明摘要、图片数量和发布时间。
- 交互：整卡点击进入详情页，hover 只做轻微上浮和图片柔和放大。

### CaseDetail

- 用途：真实案例详情页图文展示和多图浏览。
- 桌面端：双栏画廊布局；移动端：单栏图文流。
- CTA：底部或侧栏提供联系站长入口，不重复堆叠多个强按钮。

## 10. 可访问性要求

- 所有按钮和表单控件必须有明确 label。
- 图片必须有 alt 文本，装饰图可为空 alt。
- 锁定内容不能只用颜色表达状态（配合图标+文字）。
- 移动端点击目标不小于 44px。
- 键盘可访问后台核心操作。
- 对比度满足 WCAG AA 标准。
- 锁定区域使用 aria-label 说明权限要求。
- 弹窗必须支持 Esc 关闭、焦点锁定和关闭后返回触发按钮。
- 图片 alt 规则：图库封面使用图库标题，真实案例图片使用案例标题 + 序号，装饰图使用空 alt。
- 动效必须尊重 `prefers-reduced-motion`，禁用非必要位移和呼吸动画。

### 10.1 可访问性检查方法

- 使用 Lighthouse 检查核心页面，Accessibility 目标 >= 90。
- 使用键盘完成登录、搜索、图库详情锁定 CTA、联系浮层、规则弹窗和后台批量操作。
- 抽样检查黑金、浅奶油、灰色标签和状态 badge 的颜色对比度。
- 移动端点击目标抽样不小于 44px，浮动入口和底部导航不互相遮挡。

## 11. 动效规范

- 页面切换：无硬跳转，使用 Nuxt page transition（fade 200ms）
- 卡片 hover：轻微上浮 shadow（translateY(-2px 到 -4px) + box-shadow 增强），封面图 scale 1.02-1.04
- 标签选中：background-color transition 150ms
- 锁定区域：无动画，避免误导为可交互
- 移动端 Tab 切换：无额外动画，即时响应
- 图片加载：骨架屏占位 → fade-in 300ms
- 浮层进入：150-220ms，使用 opacity + translateY + scale，避免弹跳动画。
- 联系消息入口：允许轻微跳动或呼吸动效，周期不短于 4 秒，不使用高频抖动。
- 表单 focus：边框变深 + 轻微 ring，不使用强色荧光边框。
- 后台操作反馈：按钮 loading、toast、modal 关闭应有明确状态过渡，避免点击后无反馈。

## 12. 间距与排版

- 页面内边距：桌面 20-24px，移动 16px
- 卡片间距：桌面 10-12px，移动 8px
- 区块间距：16-24px，首页重点分区可扩大到 28-36px 形成杂志留白
- 标题字号：页面标题 18px，区块标题 13px，卡片标题 11px
- 正文字号：12-13px，行高 1.4-1.6
- 标签字号：9-10px
- 圆角：普通卡片 10-14px，重点卡片 16-20px，浮层/弹窗 20-28px，标签 pill 14-999px，按钮 8-999px
