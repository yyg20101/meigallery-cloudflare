# UI 设计规范

## 1. 设计目标

- 面向手机端和网页端，优先保证浏览效率、图片展示质量和搜索筛选体验。
- 视觉应克制、清爽、内容优先，避免低质猎奇感。
- 后台应偏工作台风格，信息密度高，操作路径短。

## 2. 视觉风格

**杂志编排型** — 白底留白、精致排版、图文并重、标签清晰、浏览发现感强。

核心视觉特征：
- 白底/浅灰底，大量留白
- 图片是主视觉元素，文字辅助
- 标签和分类清晰可见，方便浏览发现
- 类似时尚杂志或 Pinterest 的精致排版感

配色体系：
- 主色：#111111（文字/主按钮/当前选中）
- 背景：#FFFFFF / #FAFAFA / #F8FAFC
- 边框：#E5E7EB / #F0F0F0
- VIP 标识：#EAB308（金色）
- SVIP 标识：#7C3AED（紫色）
- 免费标识：#22C55E（绿色）
- 错误/告警：#EF4444 / #991B1B
- 标签背景：#F3F4F6，圆角 pill 样式

## 3. 首页布局

**分区块流式布局** — 每个区块有独立标题和横向滚动卡片，杂志感最强。

### 桌面端（≥1024px）

结构（自上而下）：
1. 顶部导航栏：Logo | 主导航（首页/发现/标签/视频）| 搜索框 | 登录按钮
2. 精选专题区：1 大 2 小不对称卡片布局，大图 flex:2，小图 flex:1 纵向排列
3. 最新图库：4 列等宽网格，封面+标题+标签，VIP/视频角标
4. 热门标签：pill 列表横向排列，当前选中为实心黑色
5. 视频专区：暗色调 3 列等宽卡片，播放按钮居中

### 移动端（360-767px）

结构（自上而下）：
1. 顶部栏：Logo | 搜索图标 | 头像
2. 精选专题：横向滚动大卡片
3. 热门标签：横向滚动 pill
4. 最新图库：2 列规则网格
5. 底部 Tab Bar（固定）

## 4. 导航系统

### 桌面端

顶部固定导航栏：
- 左：Logo（品牌名 MeiGallery）
- 中：主导航 tabs（首页/发现/标签/视频），当前页下划线高亮
- 右：搜索输入框 + 登录按钮（未登录）/ 头像下拉（已登录）

### 移动端

底部固定 Tab Bar，4 个入口：
| Tab | 图标 | 说明 |
|-----|------|------|
| 首页 | 🏠 | 推荐+最新内容流 |
| 发现 | 🏷 | 标签分类筛选 |
| 搜索 | 🔍 | 全屏沉浸式搜索 |
| 我的 | 👤 | 用户中心/登录入口 |

当前选中 Tab：文字加粗 + 颜色 #111。

## 5. 前台页面详细设计

### 5.1 图库详情页

**桌面端 — 双栏布局**：
- 左栏（flex:3）：封面大图 → 标题/标签/元信息 → 摘要 → 公开图片网格（3列）→ 锁定图片区 → 视频区（预览+完整锁定）
- 右栏（flex:1）：会员引导卡 → 联系站长 → 相关推荐列表

**移动端 — 单栏流式**：
- 返回按钮+标题 → 全宽封面 → 标签/元信息 → 摘要 → 图片（2列）→ 锁定提示 → 视频 → 会员引导 → 相关推荐（2列）

**权限提示设计**：
- 锁定内容：dashed border + 半透明灰色遮罩（opacity:0.3）
- 明确文案：「🔒 剩余 N 张图片需要 VIP/SVIP 会员」
- CTA 按钮：实心黑色圆角按钮「了解会员权益」
- 视频锁定：暗色背景 + 锁图标 + 等级文案

**相关推荐**：
- 桌面端：右栏垂直列表，缩略图+标题+标签
- 移动端：底部 2 列小卡片

### 5.2 发现/浏览页

**筛选交互**：
- 顶部标签类型 Tab 栏：地区 | 身份 | 性格 | 风格 | 职业 | 场景 | 内容类型
- 选中类型后下方展开子标签 pill 列表
- 已选标签显示为彩色可移除 chip（蓝色/粉色等区分类型）
- 支持多标签组合筛选（AND 逻辑）
- URL 同步：`/discover?region=guangdong&personality=sweet`

**结果展示**：
- 排序选项：最新 | 最热 | 随机
- 结果统计：「共 N 个图库」
- 桌面端 4 列网格，移动端 2 列网格
- 底部分页导航

### 5.3 搜索页

**移动端为沉浸式全屏搜索**：
- 聚焦搜索框 + 返回按钮 + 搜索按钮
- 输入时实时显示搜索建议（标题匹配高亮）
- 搜索结果上方推荐相关标签（蓝色 pill，可点击添加筛选）
- 排序：综合 | 最新 | 最热

**无结果状态**：
- 大搜索图标 + 「没有找到相关内容」
- 引导文案 + 热门标签推荐

### 5.4 登录/注册页

**设计原则**：
- 极简居中卡片式布局
- Logo + slogan 在表单上方
- Turnstile 组件必须可见

**登录表单**：
- 邮箱输入框
- 密码输入框（右侧「忘记密码？」链接，v1.1）
- Turnstile 人机验证区域
- 登录按钮（实心黑色，全宽）
- 底部：「还没有账号？立即注册」

**注册表单**：
- 昵称 + 邮箱 + 密码 + 确认密码
- Turnstile 验证
- 注册按钮
- 底部：「已有账号？立即登录」

### 5.5 用户中心

**用户信息区**：
- 头像（默认占位）+ 昵称 + 邮箱

**会员状态卡**：
- 渐变背景（VIP金色/SVIP紫色/免费灰色）
- 显示：当前等级（大字）、有效期至日期
- 底部权益一句话说明

**权益对比**：
- 三栏对比：免费 | VIP(当前高亮) | SVIP
- 列出各等级可访问的内容类型

**联系站长**：
- 结构化字段列表：微信/Telegram/邮箱
- 底部提示卡：联系说明和响应时间

**功能入口**：
- 浏览历史（标注 v1.1）
- 我的收藏（标注 v1.1）
- 退出登录（红色文字）

## 6. 后台页面详细设计

### 6.1 框架结构

- **导航**：左侧固定暗色（#111）垂直导航，宽 180-200px
- **内容区**：白色卡片 + 浅灰背景
- **技术栈**：Nuxt UI v3，CSR 模式（ssr:false）
- **响应式**：窄屏时侧栏折叠为图标

导航项目：
1. 概览（Dashboard）
2. 图库管理
3. 标签管理
4. 会员管理
5. 导入任务
6. 旧站迁移
7. 站点设置
8. 审计日志

### 6.2 Dashboard

**统计卡片行**（5列等宽）：
- 图库总数（含本周增量）
- 已发布数
- 草稿数
- 会员用户数
- 导入任务数（含失败数）

**待处理事项**：
- 红色：失败的导入任务
- 黄色：待审核的草稿
- 绿色：即将到期的会员

**最近图库表格**：标题/状态/等级/标签/更新时间

### 6.3 图库管理列表

**工具栏**：页面标题 + 总数 badge | 搜索框 + 新建按钮

**状态筛选 Tab**：全部 / 已发布(96) / 草稿(32) / 已下架(0) / 归档(0)

**批量操作栏**：全选 checkbox | 已选数 | 批量设标签 / 批量改等级 / 批量下架

**表格列**：checkbox | 封面缩略图 | 标题 | 状态(badge) | 所需等级 | 标签 | 媒体统计 | 更新时间 | 操作(编辑/预览/发布/下架)

### 6.4 导入任务

**上传区域**：虚线边框拖拽区，支持点击上传，限制 2GB

**任务列表表格**：任务ID | 状态(badge) | 文件名 | 总数 | 成功 | 失败 | 创建时间 | 操作(详情/错误报告)

**任务状态色**：
- 进行中：蓝色
- 完成：绿色
- 部分失败：红色
- 排队中：灰色

## 7. 卡片设计规范

### GalleryCard

```
┌──────────────────┐
│  [封面图 16:9]   │  ← 圆角 6px，占满宽度
│         [VIP] ←──│  ← 右上角角标（金色/紫色/视频标记）
├──────────────────┤
│ 标题              │  ← 11-12px，font-weight:500，单行截断
│ [标签1] [标签2]   │  ← 9-10px，灰底圆角 pill
└──────────────────┘
```

角标类型：
- VIP：金色背景 #EAB308 白字
- SVIP：紫色背景 #7C3AED 白字
- 视频：半透明黑色背景 + ▶ 图标
- 免费：不显示角标

### TagChip

- 默认：#F3F4F6 背景 + #333 文字，圆角 16px
- 选中：#111 背景 + #FFF 文字
- 可移除：彩色背景 + ✕ 按钮

## 10. 可访问性要求

- 所有按钮和表单控件必须有明确 label。
- 图片必须有 alt 文本，装饰图可为空 alt。
- 锁定内容不能只用颜色表达状态（配合图标+文字）。
- 移动端点击目标不小于 44px。
- 键盘可访问后台核心操作。
- 对比度满足 WCAG AA 标准。
- 锁定区域使用 aria-label 说明权限要求。

## 11. 动效规范

- 页面切换：无硬跳转，使用 Nuxt page transition（fade 200ms）
- 卡片 hover：轻微上浮 shadow（translateY(-2px) + box-shadow 增强）
- 标签选中：background-color transition 150ms
- 锁定区域：无动画，避免误导为可交互
- 移动端 Tab 切换：无额外动画，即时响应
- 图片加载：骨架屏占位 → fade-in 300ms

## 12. 间距与排版

- 页面内边距：桌面 20-24px，移动 16px
- 卡片间距：桌面 10-12px，移动 8px
- 区块间距：16-20px
- 标题字号：页面标题 18px，区块标题 13px，卡片标题 11px
- 正文字号：12-13px，行高 1.4-1.6
- 标签字号：9-10px
- 圆角：卡片 6-8px，标签 pill 14-16px，按钮 6-8px
