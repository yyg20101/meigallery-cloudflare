# MeiGallery App 1.0 高保真交互原型

## 用途

本原型用于客户需求确认和研发交互评审，不是生产 App 代码。它把 PRD 中的关键业务规则转换为可操作界面，让客户直接体验正常路径、权限门槛、后台审核和异常状态。

## 打开方式

可直接打开 `index.html`。为避免部分浏览器限制本地资源，推荐在仓库根目录运行：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/docs/app/interactive-prototype/
```

## 已实现的交互场景

1. 欢迎与手机号登录
2. 真人发现、分类和地区筛选
3. 真人详情、喜欢、关注与“发起话题”入口
4. 五级会员结构、站内会员申请与管理员发放演示
5. 平台接收话题、发送状态、运营回复与会员到期只读
6. 站内通知、金币余额与不可覆盖明细
7. 后台真人认证、退回与发布
8. 后台平台会话、会员发放、金币申请与独立审批

支持左侧目录、底部上一步/下一步和键盘方向键切换。界面中带粉色呼吸描边的控件是当前建议操作点。右侧持续显示本场景不可变规则与预期结果。

## 业务边界

- 注册用户仅为观看者，不自动成为公开真人。
- 公开列表只显示管理员创建或认证发布的真人资料。
- 当前真人资料主要由平台依据授权素材维护，界面不会暗示真人本人运营。
- 用户可提交会员申请，但只有管理员 grant 生效后才获得会员权限。
- 只有有效会员可以创建和发送平台话题；当前话题由平台运营接收和处理。
- 不展示在线状态、精确距离、真人已读、真人正在输入或保证回复。
- App 1.0 不包含支付、充值、礼物和装扮购买。
- 金币仅能通过后台加币或扣币申请改变，审批后生成不可覆盖流水。

## 演示素材与图标许可

人物图片由 OpenAI ImageGen 生成，均为明确成年且完全虚构的演示对象，不对应真实人物。界面图标统一使用 Tabler Icons 3.34.1，许可文件位于 `assets/icons/LICENSE-tabler.txt`。

## 视觉方向与保真检查

视觉方向参考保存在：

- `assets/concept-viewer.png`：原型演示器布局方向
- `assets/concept-mobile.png`：移动端视觉方向
- `assets/concept-admin.png`：管理后台视觉方向

实现时采用以下五项对照标准：

1. 演示器保持左侧场景、中央设备、右侧规则、底部推进的四区结构。
2. 移动端保持高质量人物内容优先、克制玫红强调色和原生 App 信息密度。
3. 管理后台采用中性灰工作台与单一玫红操作强调，不把后台做成营销页面。
4. 所有关键业务状态直接显示在界面，不依赖讲解者口头补充。
5. 动效只用于场景切换、热点提示、操作反馈和状态变化，并支持 `prefers-reduced-motion`。

## 截图参数

客户文档截图使用 `1800 × 1100` 桌面视口，保留场景目录、设备界面和规则说明，确保单张图即可理解“操作、规则、结果”。
