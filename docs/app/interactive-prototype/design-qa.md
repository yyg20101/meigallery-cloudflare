## 全景与聚焦对照结论

全景对照确认了顶栏、左侧目录、中央演示画布、右侧说明区和底部前后页控制的整体结构。逐页设计库保持既有粉白品牌、深色机框、轻灰画布、粉色主按钮和低饱和状态色，同时将左侧 8 个旅程升级为 92 个 Page ID 目录，将右侧场景说明升级为单页目标、入口、状态和验收说明。

聚焦对照用于检查重要细节：

- 移动端：390 × 704 机框、刘海位置、推荐页信息层级、搜索、频道、真人双列卡片、认证标识、人物裁切、底部四 Tab 和主品牌色。
- 管理后台：深色领域导航、白色工作台、列表/详情双栏、审核检查项、主次按钮、边框、圆角和页面密度。

对照后未发现需要额外裁切才能判断的重要区域，因此不再拆分更小区域。

## 必查设计表面

### 字体与排版

- 使用中文系统字体栈，PingFang SC 为 macOS 首选，标题、正文、辅助信息和状态标签层级清楚。
- Page ID、设计路由和小型后台元数据采用更小字号但仍保持可辨识，不与主标题竞争。
- 未发现文字重叠、异常截断、行高不足或窄屏标题越界。
- 与视觉基准的细小字重差异来自系统字体渲染，属于可接受的平台差异。

### 间距与布局节奏

- 桌面三栏、顶栏和底栏几何与既有原型保持一致；页面目录和说明侧栏均独立滚动。
- 手机预览在 1800 × 1100 下为 390 × 704；在 1280 × 720 下仍完整露出持久导航；390 × 844 窄屏通过抽屉展示目录与页面说明。
- 页面卡片、筛选标签、按钮、表单和后台工作台间距一致，无重叠和持久控件被遮挡问题。

### 颜色与视觉 Token

- 品牌粉、深粉、白色、轻灰画布、深色后台导航及成功/警告/危险状态色与既有原型一致。
- 主操作保持粉色实心；次操作使用白色或轻灰；危险和受限状态不复用成功色。
- 正文和辅助文字对比清晰，焦点样式可见，未发现因低对比导致的核心信息丢失。

### 图片与资产

- 全部人物照片使用本地高质量虚构成年人物素材，没有使用占位图、CSS 人像或拉伸图片。
- 推荐页双列卡片保持人物面部和上半身可见；详情页使用更大沉浸式裁切。
- 图标来自同一 Tabler 风格资源目录，没有 emoji、文本符号或手绘 SVG 代替业务图标。
- 92 页自动检查未发现损坏图片。

### 文案与内容

- 观看者、真人资料、资料认证、平台运营、会员门槛和金币账本用语与 PRD 一致。
- 私信页面持续说明由平台管理员接收和处理，不暗示本人在线、输入、已读或保证回复。
- 页面未出现支付、充值、礼物、头像框、皮肤、媒体消息、系统推送或真人认领入口。

  - 复核：`mobile-phone-comparison.png` 显示机框、搜索、频道、双列卡片和底部导航与视觉基准一致。
