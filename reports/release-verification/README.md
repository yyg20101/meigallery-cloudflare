# 发布验证报告目录

本目录用于保存本地发布验证脚本生成的结构化报告，覆盖 `quick`、`local-runtime`、`dev-rehearsal`、`release` 等模式。

提交规则：

- 仓库只提交本说明文件，不提交运行产生的 JSON 报告、日志或其他临时产物。
- 每次验证都会刷新 `latest.json`，并额外写入一个带时间戳的历史报告文件。

生产部署闸门：

- 生产部署只能读取通过的 `release` 模式报告。
- 报告必须与待发布 commit 对应，且工作区、有效期等条件满足部署校验。
- `quick` 报告只代表基础质量门禁通过，不能直接作为生产放行凭据。
