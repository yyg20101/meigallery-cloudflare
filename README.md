# MeiGallery Cloudflare

基于 Cloudflare Workers、Workers Assets、D1、R2、Turnstile 的中文响应式图库平台，用于展示授权写真和视频内容。项目当前不使用 Cloudflare Pages；Cloudflare Stream 视频能力保留为规划项，尚未接入生产链路。
